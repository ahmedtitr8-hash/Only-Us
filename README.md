# نتابع سوا 🎬

موقع بسيط تتابع فيه أي فيديو مع خويك بنفس اللحظة (يوتيوب أو رابط مباشر mp4/m3u8)، مع مايك صوت وشات نصي. لشخصين بس بكل غرفة.

**بدون سيرفر، بدون Node.js، بدون VPS ولا Render — موقع ثابت 100% يشتغل مباشرة على GitHub Pages.**

## كيف يشتغل بدون سيرفر؟
كل التواصل بينك وبين خويك (فيديو + شات + صوت) يمشي **مباشر بين المتصفحين** عن طريق WebRTC. نستخدم مكتبة PeerJS اللي تعتمد على بروكر عام مجاني بس للتعارف الأولي (يعرّف كل متصفح بالثاني)، وبعدها الاتصال يصير مباشر بينكم بدون أي سيرفر من طرفنا. هذا البروكر مجاني وما يكلفك ولا فلس، ومناسب تمام للاستخدام الشخصي بين شخصين.

## الرفع على GitHub Pages
```bash
git init
git add .
git commit -m "أول نسخة من نتابع سوا"
git branch -M main
git remote add origin https://github.com/USERNAME/watch-together.git
git push -u origin main
```

بعدها بالريبو على GitHub:
1. روح **Settings → Pages**
2. تحت "Build and deployment" اختر Source: **Deploy from a branch**
3. اختر Branch: **main** والمجلد **/ (root)**
4. احفظ — بعد دقيقة أو دقيقتين بيصير عندك رابط زي:
   `https://USERNAME.github.io/watch-together/`

هذا الرابط تفتحه أنت، تضغط "إنشاء غرفة"، وينسخ لك رابط فيه `?room=...` تشاركه مع خويك — هو يفتحه وينضم مباشرة.

## تجربته محليًا قبل الرفع
ما يحتاج تثبيت شي، بس المتصفحات ما تسمح بالمايك على `file://` مباشرة، فشغّل سيرفر بسيط محلي:
```bash
python3 -m http.server 8000
```
وافتح `http://localhost:8000`

## ملاحظات مهمة
- **لازم صاحب الغرفة يكون فاتح الصفحة** وقت ما يدخل الثاني (زي أي مكالمة مباشرة، ما فيه تخزين على سيرفر)
- المايك يشتغل بين شخصين بس بالغرفة
- HTTPS مطلوب للمايك — GitHub Pages يعطيك HTTPS تلقائي، فما فيه مشكلة
- الفيديوهات المحمية بـ DRM (نتفلكس، شاهد، وغيرها) ما تشتغل لأنها ما تسمح بتضمينها خارج تطبيقها
- إذا حصل ازعاج بالاتصال أو تأخير بسيط بالتعارف الأولي، السبب إن البروكر العام مشترك بين مستخدمين كثير حول العالم — نادرًا ما يصير، وما له علاقة بموقعك
